# APC-Q1-Proj.
This folder contains the Python codes used to create three seperate graphs for our APC Q1 project. 
Our three graphs contain:
1.) Distance to base as a function of time for the three vehicles. 
2.) Trajectories of the three shells for solution 1, all impacting at time t=100s. 
3.) Trajectories of two shells for solution 2.
